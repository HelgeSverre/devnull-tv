/dev/null on TV

A big-screen client for dev-null.sh that runs as a Samsung Tizen app. It reads the public, read-only API, so it needs no login: the log is built from the developers you add on the TV. Everything below is drawn at the TV's real 1920×1080 with the site's dark tokens, scaled to fit, using real public commits from 17 October.

Design notes

  • Sizes are the site's tokens times about 2.2: body 15 → 33 px, mono 13 → 26 px, avatar 40 → 72 px, node 14 → 28 px, rail 2 → 4 px, within a 96 px safe area.
  • Focus is the only new state: a Blue Wash fill with a 4 px Commit Blue ring, the site's focus ring scaled up. Blue still means only "you are here" or "you can act".
  • Lanes use the site's automatic hash of the user id (the API doesn't expose a chosen lane), so colors match the site for everyone who hasn't picked one.
  • No cards: commits stay rows on the rail; only link cards and quotes get an 8 px bordered block, as on the site.
  • Not on the TV: composing, starring, replying, notifications and search all need login or have no public API. Pairing later can add them.
